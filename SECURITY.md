# Security policy

Scope: vulnerabilities, leaked secrets, and data exposure in `wundertre-hq/wunder-api-docs` and the services built from it.

## How to report

Use this repository's **Security** tab > **Report a vulnerability** (<https://github.com/wundertre-hq/wunder-api-docs/security/advisories/new>). If you can't use that, email adam@wundertre.com.

Never report a vulnerability, leaked secret, or data exposure in a public issue, pull request, or discussion.

## What to include

- What's affected (file, URL, or service) and the impact.
- Steps to reproduce. Share exploit details only through the private channel above, never in public.
- Any exposed secret or data, identified without repeating it.

## Response

We'll acknowledge as soon as possible.

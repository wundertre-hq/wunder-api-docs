Requires the `crm:read` scope (the legacy `contacts:read` alias also works).

## Path parameters

<ParamTable rows={[
  { name: "id", type: "uuid", required: true, description: "The deal ID. Must belong to the caller's organization." },

## Example request

```bash
curl -X GET \
  'https://api.wundertreos.com/functions/v1/api-deals/d1e2f3a4-1111-2222-3333-444455556666' \
  -H 'Authorization: Bearer YOUR_ACCESS_TOKEN'
```

<Callout type="info" title="Is this deal won?">
Check whether <code>stage_id</code> points at a stage with <code>is_won: true</code> (see <a href="/pipelines/list">List pipelines</a>). <code>won_at</code> is set when a deal enters a won stage and is kept as history if the deal is later moved back to an open stage, so it alone does not mean the deal is currently won.
</Callout>

## Errors

| Status | `error` | When |
| --- | --- | --- |
| 403 | `forbidden` | The credential lacks the `crm:read` scope. |
| 404 | `not_found` | No deal with that ID in the caller's organization. |

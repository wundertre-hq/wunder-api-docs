Requires the `contacts:read` scope. Returns activities across all contacts in the organization, sorted by `created_at` descending. Useful for activity‑based Zapier triggers.

## Query parameters

<ParamTable rows={[
  { name: "created_since", type: "string (ISO 8601)", description: "Filter to activities with created_at >= value." },
  { name: "type", type: "string", description: "Filter by activity_type (note, email, call, meeting, tag_added, enrichment, etc.)." },
  { name: "contact_id", type: "uuid", description: "Filter to a single contact." },
  { name: "limit", type: "integer", description: "Default 100, max 200." },
  { name: "offset", type: "integer", description: "Default 0." },
]} title="Query" />

## Example request

```bash
curl -X GET \
  'https://api.wundertreos.com/functions/v1/api-activities?type=note&created_since=2026-05-01T00:00:00Z' \
  -H 'Authorization: Bearer YOUR_ACCESS_TOKEN'
```

<ParamTable rows={[

## Example request

```bash
curl -X DELETE \
  'https://api.wundertreos.com/functions/v1/api-webhook-subscriptions/wh_a1b2c3' \
  -H 'Authorization: Bearer YOUR_ACCESS_TOKEN'
```

## Response

Returns `204 No Content` on success.

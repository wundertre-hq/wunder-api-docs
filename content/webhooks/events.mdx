Every webhook delivery is a POST request with a JSON body shaped like:

```json
{
  "id": "evt_01HXYZ...",
  "type": "contact.created",
  "created_at": "2026-05-17T14:30:00Z",
  "workspace_id": "ws_...",
  "data": { /* event-specific payload */ }
}
```

The `data` field's shape depends on `type`. The following events are supported:

## Example payload: `contact.tag_added`

```json
{
  "id": "evt_01HXYZ123",
  "type": "contact.tag_added",
  "created_at": "2026-05-17T14:30:00Z",
  "workspace_id": "ws_abc",
  "data": {
    "contact": {
      "id": "c8b1f3a0-...",
      "email": "jane@example.com",
      "tags": ["lead", "vip"]
    },
    "added_tags": ["vip"]
  }
}
```

## Delivery guarantees

- **At‑least‑once** delivery
- Retries up to 5 times with exponential backoff (15s, 1m, 5m, 30m, 2h) on non‑2xx responses
- Deliveries time out after 10 seconds — keep your handler fast and queue heavy work
- Use the event `id` to dedupe in case of retries

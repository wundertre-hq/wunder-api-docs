When you start the OAuth flow at [`/oauth-authorize`](/oauth/authorize), pass a space‑separated list of scopes. Request the **minimum** scopes your integration needs.

## Example

```text
scope=contacts:read%20contacts:write%20webhooks:write
```

<Callout type="tip">
A Zapier integration that creates contacts and subscribes to triggers typically needs <code>contacts:read contacts:write webhooks:write</code>.
</Callout>

## Scope errors

Calling an endpoint without the required scope returns:

```json
{
  "error": "insufficient_scope",
  "message": "This endpoint requires the contacts:write scope.",
  "required_scope": "contacts:write"
}
```

with HTTP status `403`.

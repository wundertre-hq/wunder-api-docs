Requires the `contacts:read` scope. Powers the Zapier "Find Contact" action.

At least one of `email`, `phone`, `first_name`, `last_name`, or `tags` must be provided.

## Request body

<ParamTable rows={[
  { name: "email", type: "string", description: "Case‑insensitive exact match on email." },
  { name: "phone", type: "string", description: "Exact match on phone." },
  { name: "first_name", type: "string", description: "Case‑insensitive partial match (substring)." },
  { name: "last_name", type: "string", description: "Case‑insensitive partial match (substring)." },
  { name: "tags", type: "string[]", description: "Contact must contain ALL provided tags." },
  { name: "limit", type: "integer", description: "Default 10, max 50." },
]} title="Body" />

## Example request

```bash
curl -X POST \
  'https://api.wundertreos.com/functions/v1/api-contacts-search' \
  -H 'Authorization: Bearer YOUR_ACCESS_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{ "email": "jane@example.com" }'
```

Find every VIP customer:

```bash
curl -X POST \
  'https://api.wundertreos.com/functions/v1/api-contacts-search' \
  -H 'X-API-Key: YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{ "tags": ["vip", "customer"], "limit": 50 }'
```

## Response

```json
{
  "data": [
    {
      "id": "c8b1f3a0-4d2e-4f9a-9b1c-2d4e5f6a7b8c",
      "first_name": "Jane",
      "last_name": "Doe",
      "email": "jane@example.com",
      "tags": ["lead", "vip"],
      "status": "active",
      "created_at": "2026-04-12T09:31:22Z",
      "updated_at": "2026-05-17T11:02:08Z"
    }
  ]
}
```

Each result has the same shape as [Get contact](/contacts/get) (minus `created_by`).

## Errors

| Status | `error` | When |
| --- | --- | --- |
| 400 | `invalid_request` | No search field provided, or body is not valid JSON. |
| 403 | `forbidden` | Credential lacks `contacts:read`. |

<MethodBadge method="POST" path="/api-contacts" />

Requires the `contacts:write` scope.

## Request body

<ParamTable rows={[
  { name: "email", type: "string", description: "Primary email. Either email or phone is required." },
  { name: "phone", type: "string", description: "E.164 phone number. Either email or phone is required." },
  { name: "first_name", type: "string", description: "Given name." },
  { name: "last_name", type: "string", description: "Family name." },
  { name: "company", type: "string", description: "Company name." },
  { name: "title", type: "string", description: "Job title." },
  { name: "tags", type: "string[]", description: "Tags to apply on creation." },
  { name: "lifecycle_stage", type: "string", description: "One of lead, mql, sql, customer, evangelist." },
  { name: "owner_id", type: "string", description: "Wundertre user ID to assign as owner." },
  { name: "custom_fields", type: "object", description: "Key/value map of custom field values." },
]} title="Body" />

<Callout type="info">
At least one of <code>email</code> or <code>phone</code> is required. If a contact with the same email already exists you'll get <code>409 conflict</code>.
</Callout>

## Example request

```bash
curl -X POST \
  'https://api.wundertreos.com/functions/v1/api-contacts' \
  -H 'Authorization: Bearer YOUR_ACCESS_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
    "email": "jane@example.com",
    "first_name": "Jane",
    "last_name": "Doe",
    "company": "Acme Inc",
    "tags": ["lead"],
    "lifecycle_stage": "lead"
  }'
```

## Response

Returns `201 Created` with the new contact object:

```json
    "last_name": "Doe",
    "company": "Acme Inc",

    "lifecycle_stage": "lead",
    "created_at": "2026-05-17T14:00:00Z",
    "updated_at": "2026-05-17T14:00:00Z"
  }

```

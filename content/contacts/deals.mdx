## Example request

```bash
curl -X GET \
  'https://api.wundertreos.com/functions/v1/api-contacts/c8b1f3a0-4d2e-4f9a-9b1c-2d4e5f6a7b8c/deals' \
  -H 'Authorization: Bearer YOUR_ACCESS_TOKEN'
```

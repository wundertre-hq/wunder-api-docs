The official **WundertreOS** Zapier app lets non‑developers connect WundertreOS to 6,000+ other tools (Gmail, Slack, Google Sheets, HubSpot, Notion, Stripe, Calendly, you name it).

It's built on the same public API documented in this reference, so anything you can do in code via the API you can also do in a Zap — and vice versa.

## What you can build

- **Push WundertreOS data out**: when a contact is tagged `vip`, send a Slack DM to the account owner
- **Pull data in**: when a new Stripe customer is created, add them as a WundertreOS contact and tag them `customer`
- **Two‑way sync**: keep a Google Sheet in sync with your contact list
- **Trigger workflows**: when a deal moves to `won`, kick off an onboarding email sequence in your ESP

## How it's structured

| Concept | What it does | Powered by |
| --- | --- | --- |
| **Triggers** | Run a Zap when something happens in WundertreOS | Webhook subscriptions |
| **Actions** | Make something happen in WundertreOS as part of a Zap | REST endpoints |
| **Searches** | Find data in WundertreOS without changing it | `POST /api-contacts-search` |

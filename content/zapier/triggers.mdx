Each Zapier trigger maps directly to a public API call. Real‑time triggers create a [webhook subscription](/webhooks/create) on enable and delete it on disable; polling triggers run a `GET` every few minutes filtered by `updated_since` / `created_since`.

<Callout type="info" title="Hook lifecycle">
When you turn a Zap on, Zapier calls <code>POST /api-webhook-subscriptions</code> with its hook URL and the matching <code>event_types</code>. When the Zap is turned off or deleted, Zapier calls <code>DELETE /api-webhook-subscriptions/:id</code>. Every delivery is signed — see <a href="/webhooks/signature">Verify signatures</a>.
</Callout>

Requires the `crm:read` scope. Works with both Bearer tokens and API keys (`X-API-Key`). Returns the stages for one pipeline, sorted by `sort_order`. Use this when you already know the `pipeline_id` and only need its stage dropdown.

`GET /api-pipelines/:id` without `/stages` returns `404 not_found` — there is no single-pipeline detail route.

## Path parameters

<ParamTable rows={[
  { name: "id", type: "uuid", required: true, description: "The pipeline ID. Must belong to the caller's organization." },
]} title="Path" />

## Example request

```bash
curl -X GET \
  'https://api.wundertreos.com/functions/v1/api-pipelines/p1a2b3c4-1111-2222-3333-444455556666/stages' \
  -H 'X-API-Key: YOUR_API_KEY'
```

```js
const res = await fetch(
  `https://api.wundertreos.com/functions/v1/api-pipelines/${pipelineId}/stages`,
  { headers: { "X-API-Key": apiKey } }
);
const { data } = await res.json();
```

## Errors

| Status | `error` | When |
| --- | --- | --- |
| 403 | `forbidden` | The credential lacks the `crm:read` scope. |
| 404 | `not_found` | No pipeline with that ID in the caller's organization. |
| 405 | `method_not_allowed` | Method is not `GET`. |

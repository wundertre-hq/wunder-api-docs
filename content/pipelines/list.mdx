Requires the `crm:read` scope. Works with both Bearer tokens and API keys (`X-API-Key`). Returns every pipeline in the caller's organization, each nested with its stages sorted by `sort_order`. Exists so integrations never ask a user to type a `pipeline_id` or `stage_id` — Zapier backs its Pipeline / Stage dropdowns with this endpoint.

## Example request

```bash
curl -X GET \
  'https://api.wundertreos.com/functions/v1/api-pipelines' \
  -H 'X-API-Key: YOUR_API_KEY'
```

```js
const res = await fetch(
  "https://api.wundertreos.com/functions/v1/api-pipelines",
  { headers: { "X-API-Key": apiKey } }
);
const { data } = await res.json();
```
